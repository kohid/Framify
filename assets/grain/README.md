Image grain textures
====================

Drop a texture image here (png, jpg, webp, gif or svg, up to 1.5 MB, 60 in all)
and it shows up in Grain > Texture as "Uploaded: <file name>" on every site the
plugin is installed on. Files in `wp-content/uploads/framify-grain/` work the
same and survive plugin updates.

How it is used: dark ink on a light or transparent background becomes the
grain, painted in the Grain colour inside the shape. Transparent PNGs and
black-on-white scans both work. The image stretches to cover the shape, so
use a wide, seamless-edged texture; Grain amount sets how strong it is.
